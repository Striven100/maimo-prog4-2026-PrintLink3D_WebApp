PASOS RÁPIDOS

1. Abrir esta carpeta en Visual Studio Code.
2. En la terminal:

   npm install
   npm run dev

3. Abrir:

   http://localhost:3000

API:

   http://localhost:3000/api/models
   http://localhost:3000/api/models?q=soporte
   http://localhost:3000/api/models?material=PLA

Subir a GitHub:

   git init
   git add .
   git commit -m "Initial PrintLink 3D web app"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/NOMBRE_DEL_REPO.git
   git push -u origin main

Vercel:

   Importar el repo desde Vercel y desplegar como proyecto Next.js.
